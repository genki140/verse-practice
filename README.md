## 合意の扱い

ユーザー指定を要件とし、質問せずに補った選択を「推奨初期値」として本文に記載しています。これらは実装時に追加質問なく採用できます。特に初期問題数は6カテゴリー各2問の計12問です。「すべて」では10問、個別カテゴリーでは2問です。10問未満の水増し出題はしません。各カテゴリー10問以上への増補は別のコンテンツ拡張であり、初期実装の完了条件ではありません。
